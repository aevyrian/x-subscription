# MeTube Docker 部署教程

> MeTube = 自托管 `yt-dlp` 网页界面，支持 YouTube 及数十个站点视频 / 音频 / 字幕 / 缩略图下载，支持播放列表、频道、订阅自动追更。多架构镜像 `ghcr.io/alexta69/metube`，默认端口 `8081`。

## 1. 功能与日常使用

1. 打开 `http://服务器IP:8081`，粘贴视频链接，点 `Add`。
2. `Advanced Options` 选择清晰度、格式：
   - 视频：`Best` / `720p` / `1080p` 等
   - 音频：勾选音频模式，存为 `mp3 / m4a / opus`
3. 播放列表 / 频道：粘贴列表页链接，按需设置 `Playlist item limit`。
4. 订阅追更：`Subscriptions` 中添加频道 / 列表地址，设置检查间隔，新发布自动入队。
5. 成品管理：`Completed` 查看、播放、下载到本地；开启 `DELETE_FILE_ON_TRASHCAN=true` 后，在网页端删除同步删除服务器文件。
6. Cookie 应对登录 / 会员 / 年龄限制视频：
   - 浏览器安装导出 Cookie 扩展，导出 `cookies.txt`
   - 在 `Advanced Options` 中 `Upload Cookies` 上传，指示灯变亮即生效
   - 失效时 `Delete Cookies` 后重新上传
7. 浏览器联动：
   - Chrome / Firefox 安装 `MeTube Downloader` 扩展，右键发送链接
   - 扩展跨域调用需设置 `CORS_ALLOWED_ORIGINS=*`
   - 手机分享：iOS 快捷指令 / Android MeTube Mobile

## 2. 核心配置速览

日常最常用环境变量：

| 变量 | 作用 | 推荐值 |
|---|---|---|
| `DOWNLOAD_DIR` | 视频保存目录 | `/downloads` |
| `AUDIO_DOWNLOAD_DIR` | 音频分离保存 | `/downloads/audio` |
| `STATE_DIR` | 队列 / 订阅状态持久化 | `/downloads/.metube` |
| `TEMP_DIR` | 下载临时文件，建议放 SSD | `/downloads` |
| `PUID / PGID` | 运行用户 UID / GID，需与宿主机目录权限匹配 | `1000 / 1000` |
| `UMASK` | 新文件权限掩码 | `022` |
| `OUTPUT_TEMPLATE` | 单视频命名 | `%(title)s.%(ext)s` |
| `OUTPUT_TEMPLATE_PLAYLIST` | 列表命名 | `%(playlist_title)s/%(title)s.%(ext)s` |
| `OUTPUT_TEMPLATE_CHANNEL` | 频道命名 | `%(channel)s/%(title)s.%(ext)s` |
| `MAX_CONCURRENT_DOWNLOADS` | 并发下载数 | `3` |
| `CLEAR_COMPLETED_AFTER` | 完成列表自动清理秒数，0 表示保留 | `0` |
| `YTDL_OPTIONS` | 全局 yt-dlp 参数 JSON | 按需设置字幕、缩略图、限速 |
| `PORT` | 网页端口 | `8081` |
| `URL_PREFIX` | 反向代理子路径，如 `/metube` | `/` |
| `HTTPS` / `CERTFILE` / `KEYFILE` | 容器内直接 HTTPS | 反代场景保持 `false` |

`YTDL_OPTIONS` 示例：写字幕 + 缩略图：

```json
{"writesubtitles": true, "subtitleslangs": ["en"], "writethumbnail": true, "updatetime": false}
```

命名 Cookbook 参考官方 Wiki：`YTDL_OPTIONS Cookbook`、`OUTPUT_TEMPLATE Cookbook`。

## 3. 服务器前置要求

1. 已安装 Docker + Docker Compose v2：
```bash
docker -v
docker compose version
```
2. 准备数据目录，例如 `/opt/metube/downloads`，记录 UID/GID：
```bash
id -u; id -g
mkdir -p /opt/metube/downloads
```
3. 放行安全组 / 防火墙 `8081/tcp`，或只放行 `80/443` 走反代。

## 4. 一键 Docker Run（试运行）

```bash
docker run -d \
  --name metube \
  --restart unless-stopped \
  -p 8081:8081 \
  -v /opt/metube/downloads:/downloads \
  ghcr.io/alexta69/metube
```

打开 `http://服务器IP:8081` 验证页面正常即成功。

## 5. 生产推荐 Docker Compose

在指定目录新建 `compose.yaml`，例如 `/opt/metube/compose.yaml`：

```yaml
services:
  metube:
    image: ghcr.io/alexta69/metube
    container_name: metube
    restart: unless-stopped
    ports:
      - "8081:8081"
    volumes:
      - /opt/metube/downloads:/downloads
      # 可选：配置文件持久化
      # - /opt/metube/config/ytdl-options.json:/config/ytdl-options.json:ro
    environment:
      - PUID=1000
      - PGID=1000
      - UMASK=022
      - DOWNLOAD_DIR=/downloads
      - AUDIO_DOWNLOAD_DIR=/downloads/audio
      - STATE_DIR=/downloads/.metube
      - TEMP_DIR=/downloads
      - MAX_CONCURRENT_DOWNLOADS=3
      - DELETE_FILE_ON_TRASHCAN=false
      - DEFAULT_THEME=auto
      - LOGLEVEL=INFO
      - OUTPUT_TEMPLATE=%(title)s.%(ext)s
      - OUTPUT_TEMPLATE_PLAYLIST=%(playlist_title)s/%(title)s.%(ext)s
      - OUTPUT_TEMPLATE_CHANNEL=%(channel)s/%(title)s.%(ext)s
      # - YTDL_OPTIONS={"writesubtitles": true,"subtitleslangs": ["en"],"writethumbnail": true}
      # - YTDL_OPTIONS_FILE=/config/ytdl-options.json
```

启动：

```bash
cd /opt/metube
docker compose up -d
docker compose ps
docker compose logs -f metube
```

更新：

```bash
docker compose pull
docker compose up -d
docker image prune -f
```

如需跟随 yt-dlp nightly，可加 `YTDL_NIGHTLY_UPDATE_TIME=03:30`，每天该时间自动升级并重启。

## 6. 反向代理（可选，推荐）

Nginx 关键点：透传 WebSocket：

```nginx
location /metube/ {
  proxy_pass http://127.0.0.1:8081/;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
  proxy_set_header Host $host;
}
```

对应需设置 `URL_PREFIX=/metube/`。Apache / Caddy 示例见官方 Wiki `Reverse-proxy-configurations`。

## 7. 排错清单

```bash
docker exec -it metube sh
cd /downloads
yt-dlp --version
```

1. 下载失败先在容器内用 `yt-dlp URL` 直测，确认是否为站点限制 / Cookie 失效 / 参数错误。
2. 权限问题：检查宿主机目录属主与 `PUID/PGID` 是否一致，必要时 `chown -R 1000:1000 /opt/metube/downloads`。
3. 文件名过长报错：在 `YTDL_OPTIONS` 加 `trim_file_name` 或 `restrictfilenames`。
4. 订阅未更新：调小 `SUBSCRIPTION_DEFAULT_CHECK_INTERVAL`，检查 `STATE_DIR` 是否持久化。

## 8. 等你发账号后 Agent 直连部署流程

请提供：服务器 IP、SSH 端口、用户名、密码或密钥、指定目录（如 `/opt/metube`）、期望外网端口、是否需要反代 / HTTPS。

收到后 Agent 将执行：建目录 → 写 `compose.yaml` → `docker compose up -d` → 健康检查 → 打开页面验证 → 回传访问地址与账号状态。
